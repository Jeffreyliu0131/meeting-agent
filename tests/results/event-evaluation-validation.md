## 发现并修正的评测问题

1. 新隔离执行器最初漏复制两个HTML入口，已补齐并通过实际构建。
2. 原加速负载替身只在返回值放token，没有触发onUsage；服务按未知usage保守保留62500 token，64次即达400万上限，调度不同会停在357/360。修复替身回调并增加用量／保留输入断言，未调高产品预算。实际供应商计量另验。
3. node_modules符号链接令esbuild嵌入原仓库路径，不能用这种构建做字节级包比对。现用独立依赖复制（支持时copy-on-write），14文件严格匹配，无字符串归一化或忽略差异。
4. 流式测试固定30ms睡眠在负载下偶发失败，改为有界实际事件等待；仍验证提交前PCM、暂定／final隔离、短尾包及无缺口。
