3. UI 不能冒充采音适配器，没有 Node／process；1440×1024、1024×768、800×600 与 200% 页面缩放无全页水平溢出。
4. 本地 HTTP 测试服务 → 实际供应商适配器 → schema／来源校验 → 独立窗口预览 → 表格与关系表达 → 来源绑定 → 不打断草稿的新版本 → 十进制试算保存。

## 仍然存在的实施限制

- 无真实模型／转写凭证，无法验收 Agent 自主选择质量、更新准确性、中英文保真、真实延迟和成本。添加凭证后应先跑四类合成输入及变体，再做有人参与的真实会议。
- macOS 与 Windows 都有输入与构建路径，但仅 macOS 有原生运行证据；Windows 交叉构建不是 Windows 真机验证。
- 音频为 5 秒 PCM 切片，并非 Realtime 流；断句、静音门限、重叠发言、回声和积压行为仍需真实会议校准。当前使用默认麦克风，没有设备选择器、自动说话人分离或平台身份集成。
- HTML/SVG 被动内容可运行；任意生成 JS 被禁止，交互推演使用可信控件。复杂自动布局、节点重叠检测及所有载体的 200% 细节可读性没有完整人工验收。
- 时间安排保留原表达；没有工作日历、节假日、关键路径或自动日期算术工具。未知工期不应被写成确定承诺。
- 长会议上下文上限 90,000 字符，超过后显式报错；无检索式长期记忆。SQLite 目前保存聚合快照；大规模历史分页、加密、应用内删除、自动迁移与崩溃损坏恢复尚未实现。
- 已保存试算保留基线并标过期；重新计算通过当前公式创建新试算，尚无一键迁移旧参数的专门界面。
- 生成语义仍需审阅；schema、来源存在和数值工具不能证明所有模型判断正确。源文翻译适配器和 revision 校验已实现，但真实翻译质量未测试。
- 包未签名／公证，使用默认应用图标；本轮提供本地应用目录，没有验收安装器、Mac Intel、Windows ARM、自动更新或商店分发。

## 后续验证顺序

1. 在 `.env` 或用户数据目录 `provider.env` 配置模型和转写凭证；`npm run test:model` 保存真实响应，人工核对 fixtures 的 expected 项并补充未调优过的变体。
2. macOS 上完成明确授权的线上系统采音配置，戴耳机验证远端与本机两条通道；与真实线下普通话、英语、混说分别记录。
3. 在 Windows x64 上运行同一应用目录，重复桌面、设备、权限、采音与停止恢复矩阵。
4. 用真实讨论测表达质量与速度，再决定是否替换为实时转写流和增加长会议检索；不靠增加静态模板掩盖理解问题。
