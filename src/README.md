# 产品代码目录

当前只有目录占位，无产品功能、依赖或启动命令。下一轮按[实施计划](../docs/implementation-plan.md)开发。

| 目录 | 放置内容 | 不应承担 |
|---|---|---|
| `desktop/` | Electron main／preload、可信React外壳、事件列表、窗口与入口 | 生成内容不拥有此层权限 |
| `service/` | 会话生命周期、持久化、调度、命令、订阅、提供商调用 | 不在数据库事务里等待模型 |
| `integrations/` | 麦克风／系统采音／平台流／回放适配、STT与身份映射 | 不把匿名声音猜成姓名 |
| `agent/` | 增量理解、表达规划、生成、语义校验、定向修复与提示规范 | 不硬编码样例→固定图 |
| `domain/` | 对象关系、版本、来源、试算、决定范围、确定性工具 | 不依赖React或生成DOM |
| `renderers/` | 文档／表格、图语言、SVG、chart、HTML宿主与绑定 | 不直接写会议事实或读取凭证 |
| `contracts/` | schema、共享类型、命令、错误、订阅与载体协议 | 不引入桌面密钥或数据库驱动 |

开发可以在各目录内细分；跨模块通过契约连接。构建方式在P0选择，代码实际落地后更新此说明。不要为占位目录编造“测试通过”或“服务在线”。
