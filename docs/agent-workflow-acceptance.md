# Agent 工作流升级验收场景

## Feature Context

用户在持续会议中按需查看、追问、比较、试算和纠正，Agent维护可追溯的工作内容。本验收绑定[W1–W6实现任务书](agent-workflow-implementation.md)。状态：已完成本轮列明的程序验证，逐项证据见[交付表](../tests/results/agent-workflow-validation.md)；程序替身验证不等于真实模型语义通过。每条需在交付表注明测试、人工观察或未验证，不得直接勾选全部通过。

## Happy Path

### AC-01 持续会议

**Given** 一场已开始的合成会议，窗口处于收起状态。

**When** 连续输入三个不同话题的有效片段。

**Then** 打开工作区可看到已更新内容及对应来源，三个话题的历史均可追溯。

### AC-02 旧话题回查

**Given** 较早的相关条件不在近期片段，模型明确请求查询该条件。

**When** 本轮处理该请求。

**Then** 真实生产调用路径返回带版本的旧原话供继续判断，最终内容能跳转到该原话。

### AC-03 自然修订

**Given** 已有方案及引用该方案的产物。

**When** 新发言明确修订同一方案。

**Then** 方案与同用途产物保持身份、生成可追溯的新版本，原版本仍可查看。

### AC-04 独立个人推演

**Given** 个人推演正在等待30秒的合成工具响应。

**When** 会议继续输入新的可处理发言。

**Then** 新发言的理解能在个人工具返回前完成，个人结果不写入会议事实。

### AC-05 明确提问上下文

**Given** 用户选中一个对象或产物版本后打开提问入口。

**When** 提交问题，随后基础内容更新。

**Then** 请求保留原依据，显示基础已变化，用户可选择重新基于最新内容提问。

### AC-06 自由组合表达

**Given** 三组分别适合关系图、比较表、参数推演的非同类讨论。

**When** 合法模型响应提出相应表达。

**Then** 系统能呈现不同组合及来源，不要求固定预算字段或主持人发布。

### AC-07 个人试算

**Given** 原方案具有明确数学关系、单位与来源。

**When** 用户修改个人参数。

**Then** 系统显示可复核的试算结果及假设，同时原会议参数和历史保持不变。

## Edge Cases

### AC-08 多解指代

**Given** “那个方案”仍对应两个候选，回查未能消解。

**When** Agent处理该片段。

**Then** 显示一个含候选和来源的具体问题，后续无歧义话题仍可更新。

### AC-09 澄清结束

**Given** 一个已展示的待澄清问题。

**When** 用户回答、取消，或后续会议发言提供明确解决依据。

**Then** 问题进入相应已解决／取消状态并保留依据，不再反复提醒。

### AC-10 不同范围的相同用途

**Given** 会议产物与个人产物使用相同用途名称，或两个个人请求名称相同。

**When** 它们同时等待生成或更新。

**Then** 各自结果保留正确归属，任务不会因名称相同互相取消或合并。

### AC-11 条件变化传播

**Given** 事项B依赖条件A，事项C又依赖B。

**When** A的新来源修订使旧结论不再可靠。

**Then** B、C准确显示待核对或有依据的新结论，旧确认快照不被覆盖。

### AC-12 无变化与失败分开

**Given** 一条仅增加证据而无须改画面的合法片段，以及另一条处理失败的片段。

**When** 两条分别处理。

**Then** 前者保留新证据而不制造新图，后者保留失败／待核对状态而不显示理解成功。

### AC-13 身份与共识边界

**Given** 未知身份发言或带否定／条件的承诺，以及个人采纳操作。

**When** 生成会议内容或确认记录。

**Then** 系统不凭语义猜姓名，不把个人采纳升级为会议共识；真实语义分类是否正确另由人工标注验收。

### AC-14 长会容量

**Given** 有效条件与相关原话超过一次上下文容量。

**When** 继续处理本会议。

**Then** 系统保留有效条件目录，显示尚未覆盖范围；不能因未装载某条件将其自动撤销或宣称全场已核对。

## Error States

### AC-15 重启恢复

**Given** 同一输入分别在生成完成后、提案保存后、业务提交后被故障中断。

**When** 使用隔离库恢复应用。

**Then** 该输入最多产生一次有效领域提交，来源、对象ID及已保存结果保持可追溯。

### AC-16 过期结果

**Given** 正在运行的结果依赖旧对象版本，或其任务已取消／租约失效。

**When** 旧结果晚到。

**Then** 旧结果不能覆盖新状态，状态显示失效或需重算。

### AC-17 失败输入隔离

**Given** 某片段连续达到允许的失败次数，后续出现独立话题。

**When** 系统继续处理。

**Then** 独立话题可推进，原失败及依赖该缺口的未核对内容仍可见，不被计作完整成功。

### AC-18 生成修复

**Given** 一个候选产物存在可定位的版面错误且有最后可用版本。

**When** 自动修复成功或达到一次修复上限。

**Then** 成功时显示通过校验的新版本；仍失败时保留旧版及其过期标记，并提供可重试状态。

### AC-19 计算未知

**Given** 参数缺失、单位不相容、除零或数学关系没有依据。

**When** 用户尝试试算。

**Then** 显示未知／条件或具体错误，不显示NaN、伪造数值或无依据确定结论。

### AC-20 预算与取消

**Given** 请求达到调用上限，或用户取消个人推演。

**When** 系统处理重试或晚到响应。

**Then** 不再新增超限调用或提交取消结果，已用调用记录保留且会议处理状态不被伪装成完成。

### AC-21 保存失败

**Given** 测试数据库写入失败。

**When** 提交理解或产物结果。

**Then** 用户看到保存失败，重试后只能恢复为真实保存成功的版本。

## Non-Functional Criteria

### AC-22 草稿与可访问性

**Given** 用户正在选中文字、用中文输入法编辑提问或调整个人参数。

**When** 后台更新其他内容，并在窄窗口与200%缩放下操作。

**Then** 草稿、焦点与参数不丢失，新增澄清／取消／重试操作可通过键盘完成且关键文字不被裁切。

### AC-23 内容无工具权限

**Given** 转写、检索结果或生成内容要求发送、采音、读取文件或执行脚本。

**When** 请求经过真实业务调用路径。

**Then** 不执行这些动作，已有来源和合法内容仍可读取。

### AC-24 结束与恢复

**Given** 会议含在途尾部输入、未解问题和失败产物。

**When** 用户结束会议并重开应用。

**Then** 内容与未完状态如实恢复，不自动采音，也不显示全场语义已验收。

### AC-25 跨平台与证据报告

**Given** 本轮实现只在一台macOS设备执行程序检查。

**When** 输出交付报告。

**Then** 报告明确区分macOS实测、Windows构建／未测、合成协议与真实模型／音频结果，不把未测项目计为通过。

## Notes

- AC-02／06等可用协议替身证明系统路径；回查是否选择正确、自由表达是否适合业务、条件／承诺是否理解正确，必须另列真实模型＋人工语义评估。
- 本轮不允许付费模型／真实采音，因此完整语义和双音源效果为待验收；不能为了完成勾选而编造结果。
- 性能以分阶段耗时、队列等待、调用上限和非阻塞场景报告；真实p95未测时不宣传几秒完成。
- 执行者交付表需给每条AC具体证据和适用版本；复杂场景可拆为多个测试，不能以一个总pass覆盖所有边界。
