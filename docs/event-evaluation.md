## 指标与判定

完整30项见[机器可读指标表](../tests/evals/metrics.json)。主要口径：

- 安全与确定性门槛：事件／个人污染、自动代发／代投／代确认、旧回应迁移、错误计数、假ack、无声丢失输入均不得出现。失败案例不能被平均分抵消。
- 模型：family与operation分别macro-F1≥0.90；明确目标定位≥0.95；关键字段与来源正确率各≥0.95。这些继承协作验收的建议首版门槛，不是实测成绩。错误／失败请求仍在分母中，按语言及类别报告样本数；本语料没有覆盖全部操作类别，未出现的操作不声称通过。
- 语义真实性：条件保留、收集误纳、无依据字段与有依据冲突精确率分别记录；负责人或日期编造且未标未知为硬失败。真实模型自评分不能替代独立核查。评测输入和答案由Agent起草，必须先审语料再用于正式门槛。
- 性能：final到理解提交p95≤5秒；缓存展开≤300ms；简单本地试算≤100ms，来自技术设计。完整产物／草稿时延单列。当前模型回放可观察理解和settled时间；缓存展开／UI试算计时仍需新探针，不能用测试总耗时冒充。
- 成本：M/X/P/C/R逐次调用、input/output tokens、失败与修复、每事件总量；无实际usage或已核验价格时货币成本为null。预算上限前检查，未知usage显式保留；单次在途请求可能越过token软上限，不是可承诺的硬费用封顶。
- 音频：WER/CER、数字与否定词错误、首尾包、双路覆盖；身份精度和归属覆盖率分开，unknown留在覆盖率分母。不设虚假的90%／99%门槛。
- 用户效果：事实问题正确率、寻找依据／发现变化耗时、打扰次数每人小时；先取得基线，不能用生成卡片数量当用户收益。

各比例保留分子／分母；分母0记null。p95按原始样本最近秩计算，报告样本量；不平均多个p95。固定机器、源码、模型、prompt/schema和语料hash后才比较；样本小不能外推真实分布。代码指纹包含provider及其schema依赖；模型名称不能证明供应商底层权重未变。

## 自动执行

在仓库根目录：

```sh
node scripts/evaluate.mjs --offline
node scripts/evaluate.mjs --offline --model
node scripts/evaluate.mjs --offline --model --release
```

第一条不加载凭证、不做外部模型请求。第二条增加真实模型文本评估；只读取本地`.env`或进程配置，无key时明确blocked。当前未配置。默认真实评估最多240次请求、100万已报告token；可用`MEETING_EVAL_MAX_CALLS`、`MEETING_EVAL_MAX_TOKENS`下调。每次请求60秒、每轮90秒有界；回放顺序固定。没有真实麦克风、通知、跨设备操作或日常应用重启。

每次运行在`.cache/evals/<run-id>/`生成`report.md/json`、provenance、日志、Electron报告、加速负载与包指纹。执行源为独立临时目录，依赖复制到隔离目录（可用时使用copy-on-write，避免符号链接导致构建模块路径不同）；不拷贝凭证、会议库、Git或日常包。不覆盖已有运行记录；不会写GitHub或自动安装定时任务。

退出0仅表示本轮已执行的自动检查未失败，完整产品仍可blocked；退出1表示实际检查失败；`--release`在缺真实／人工／平台证据时退出2。必须同时看`automatedStatus`和`productGate`，不能只看shell退出码。

真实模型运行后生成待填写的`human-review.json`。独立核查者填写来源／字段／条件／冲突／target的计数和逐案例证据，并确认数据集标注；用以下命令验hash并算分：

```sh
node scripts/evals/review.mjs /absolute/path/to/run /absolute/path/to/completed-review.json
```

它新建`semantic-score-*.json`，不改原模型结果、不把其他缺口改为通过。不同run、漏案例、重复案例、无证据、无分母均不能当有效评审。完整产品门槛当前仍需逐项补平台、音频与用户证据；尚无自动吞入任意附件即放行的机制。
