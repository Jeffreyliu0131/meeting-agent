# Agent 事实边界、持续跟进与结束核对

2026-09-12｜已接入本轮源码；执行与验证范围见 [session](sessions/2026-09-12-agent-reliability.md)。用户确认三个方向并授权顺序实现、验证后提交推送。本规范补充 [ADR-004](adr/004-live-agent-pipeline.md)，保留可信会话服务、独立表达队列和受控渲染。

## 1. 事实与个人探索分开

`SemanticObject.meaning` 保存 `stance`（asserted／proposed／conditional／committed／unknown）、`conditionIds`、带原话证据的 `owner`／`deadline`。`committed` 仅表示原话中报告的承诺，不是会议确认。会议级确认仍由显式 Decision 命令、范围及会议原话支持。

每段 evidence 包含原话 quote 和版本化 sources；引用必须存在于原文，负责人／日期 value 必须出现在引用文字中。日期保存原相对表达，不擅自推算自然日、工作日或归属姓名。conditional 必须绑定真实 constraint 对象。修改已有 meaning 或清除待核对状态，必须提供本批尚未处理的新发言／修订作为 changeSources；引用旧证据无法撤销条件。条件是否被新发言真正撤销仍属于模型语义判断，程序只验证证据和状态边界。

兼容旧数据库／测试供应商：缺 meaning 时作为尚未分类，不自动补成承诺；旧对象没有 changeSources 时，以新引用的原话／修订作为重新核对依据，旧引用仍不能清除待核对。恢复时从现有关系建立依赖版本基线，不重建或伪造更早历史。真实供应商请求 schema 要求显式返回 meaning（允许 null）和 changeSources，运行时可读取旧格式。

后台会议理解与会议表达生成均使用 meeting 范围投影，排除 request 原话、个人产物、个人采纳和 scenarios；个人探索保留 personal 范围。提交前再次以当前范围校验。会议确认禁止个人产物，以及包含 request 的混合来源。个人探索可读取会议，但不能回写会议对象和对象历史。

## 2. 有效条件与修订影响

当前未处理输入之外，优先保留 active 约束、未决问题、分歧、有条件事项、承诺和待核对对象，并补齐递归依赖及来源。所有显式会议决定和其来源进入上下文，而不只取最后三条。其他内容沿用词项／关系检索与近期上下文；尚非向量检索或自主检索工具循环。

上下文仍有字节上限：可缩减普通相关内容，不静默丢弃有效条件和显式绑定的个人提问上下文。必要记忆超限返回 CONTEXT_MEMORY_LIMIT，绑定产物超限返回 REQUEST_CONTEXT_TOO_LARGE；原话保留，需调整容量或缩小范围后继续。尚未实现大量有效约束的分页推理，不能宣传无限长会。

可信服务保存对象 dependencyRefs、reviewRequired 和 objectHistory。依赖包括 meaning.conditionIds、条件指向被约束对象的 conditions 关系，以及任务指向前置事项的 depends_on 关系。新关系绑定、来源修正、依赖对象改版／失效会使受影响对象待核对，并沿依赖传播。对象版本变化使既有产物失效；相关生成任务拒绝过期提交。

系统不会因为依赖变化就自动编写新日期或承诺。Agent 必须引用新证据重新理解；无法判断时保留待核对。旧对象和确认快照保存，不改写历史。`objectHistory` 是本轮开始后的对象修订记录，不伪造更早的完整事件日志。UI 按需显示当前条件与承诺依据，历史产物正文保持原版本。

## 3. 结束核对与汇总记录

每次可信状态保存时，已结束会议重新计算 closeout。检查覆盖全场已保存对象，而不是最后一次模型窗口：待处理来源、未决问题／分歧、未解除条件、缺负责人／时间／承诺的任务、未分类事项、失效决定／产物及输入缺口。

closeout 状态：pending 表示有已接收内容／表达等待处理；needs_review 表示已保存但仍有未决或失败项；ready 仅表示记录检查完成，不表示所有语义正确或会议取得共识。结束页提供按需展开的汇总会议记录及来源入口。原有 JSON 导出包含 closeout、对象历史、原话、产物和决定；恢复时重新核对，不恢复录音。

音频在途数按 meetingId 维护，结束后允许已接受音频补入并更新核对结果，不把上一场尾部算到下一场。重启遇到未完成音频记录中断缺口。无模型配置时未处理来源标为错误／待核对，不假装继续理解。队列失败先记录缺口，再释放在途标记。

结束核对为确定性检查＋已有对象的汇总呈现，不新增模型裁判调用，也不自动推断遗漏的语义。原有生成产物仍承担自由组织文字、图形和交互的职责；此检查不替换它。

## 验证边界

程序测试验证隔离、版本、原话匹配、状态转换和界面；合成模型仅验证传输协议。原话引用匹配不等于蕴含校验，正确分类提议／承诺、理解否定与隐含条件、真实长期检索和纪要完整性须由真实模型及人工标注评估。当前仍约5秒音频切片，真实中英转写、线上双方音源、真实成本／时延、Windows 真机未验收。
