# 第二版会议首页 · 设计与交互核验

final result: passed

范围：完成用户授权的独立HTML视觉稿与关键交互，不是正式应用实现。首版已被用户否定；本版随后已被用户否定，保留当时程序和视觉检查记录，不作为当前方案。新布局不是飞书逐像素复制，视觉检查通过不代表“高级感”已获用户认可。

## 参考与第一性原理

- [飞书官方云文档指南](https://www.feishu.cn/content/article/7572026952902230020)：实际检查其[首页截图](qa/references/docs-home.jpg)，观察侧栏、主操作、列表列对齐和轻量分隔。该图含官方指南的教学高亮，不冒充当前用户登录界面／最新版本。
- [Lark官方会议妙记指南](https://www.larksuite.com/zh_cn/blog/meeting-minutes)：实际检查[会议入口截图](qa/references/minutes-home.jpg)，观察会议入口和历史记录的直接关系。这里只借鉴导航／工作流，不复制其日程、加入会议、协作或卡片模块。
- 用户首次／日常进入本产品的三项任务：知道将收听什么、开始／回到当前会议、找回以前的讨论。引擎能力通过会议内容线索和可追溯原话体现，不在首页铺开能力样板。
- 用户否定的是首版的设计效果。第二版从结构重做：低对比侧栏＋连续白色内容面、紧凑开始区、时间分组会议列表；没有首页宣传大标题和大示例卡片。示例按需打开，默认日常设计稿的记录持续标为合成，首次状态无假记录。

## 主要修复和检查结论

1. 首次渲染中列表次文字过淡偏小。摘要调整至12px（小屏11px）并加深至#737d8e；时间／时长12px，主标题与列层次保留。
2. 底部预览条曾可能压住最后内容，增加整体底部预留。长列表允许正常滚动，不通过把正文缩小强塞全部记录。
3. 发现点击“查看原话”后侧栏实际消失：程序／键盘触发的点击坐标为0，被背景关闭逻辑误判。修正为仅处理目标为dialog本体的背景点击；同时加入来源／开关操作后dialog仍打开的断言，并重拍截图确认真实画面。
4. 五项视觉表面：系统字体；统一列表节奏与轻分隔；冷灰／白／克制蓝色；Lucide真实图标，无生成图片或占位图；原话、未确认条件、个人假设和示例标记分开。没有带阴影的内容卡片；抽屉／设置为必要交互浮层。
5. 没有剩余阻塞本预览的P0／P1／P2。中文窄屏标题／摘要可省略，点击能读取全文。Windows浏览器与完整无障碍未验；不声明所有界面对比度合规。
