# Agents, Everywhere — 前端风格与页面规范

设计标识：`collaborative-light-v2`（已接入本地前端、隔离内容与生成器视觉指导）。更新：2026-09-12。

用户已认可本轮 8 张概念图的整体风格：清晰、舒适、现代协作办公产品的感觉。本文依据[生成设计及 style.md 的会话](https://chatgpt.com/c/6aa41aad-b754-83ec-a77d-04c5095bdc19)中可见的规范正文与本项目行为契约整理，是**本地整合修订版，不是原始附件的逐字副本**。Chrome 组织策略拦截原附件下载；原文件仍在该会话内。本轮未上传或采用旧参考图。

整体视觉方向已获认可；用户在前端改造期间再次确认整体方向，并要求参考飞书云文档及多个模块，提升工作流与细节。精确参数属于工程选择，实际实现与验证见[前端改造记录](../sessions/2026-09-11-frontend-refresh.md)。合成会议与程序检查不证明真实模型或双端质量。

本文第5–9节保留概念稿描述与目标要求，不是完整已实现清单。当前控件、断点、草稿范围及未实现项统一见[前端实现边界](../frontend-spec.md#11-当前实现与目标差距)。

## 1. 权威与本地校准

产品行为以[会议入口](../meeting-entry-spec.md)、[语言](../language-spec.md)和[前端交互契约](../frontend-spec.md)为准；本文件负责当前视觉语言、页面构成和组件层级。设计图片及生成端文字不得新增权限、取消已有产品能力或把建议写成已完成事实。

本地整理对生成端原文作出以下必要校准：

| 生成端的描述／建议 | 本项目采用的解释 |
|---|---|
| 软件启动默认进入首页 | 启动只显示桌面轻入口且不录音；用户打开主工作窗口后，无活动会议时进入首页 |
| 电脑声音不可用，麦克风可用则仅麦克风继续 | 明示缺失通道；必须由用户明确选择仅用麦克风继续，不能静默缩小已选择的采集范围 |
| 会中保存设置／切换设备 | 全局偏好默认影响下次会议；明确“应用到当前会议”才切换当前输入，并显示过程和缺口 |
| 有限 primitive 而非任意 HTML | 保留通用基础元素和受控 HTML、SVG、结构化图表的既定路线；载体按隔离与净化契约接入，不引入任意脚本，也不缩成固定业务模板 |
| 核心问题 40px、红色收听标识 | 字号作为建议，常规标题采用 28–32px；采集正常沿用绿色和文字，红色用于错误／结束操作。整体风格认可不等于逐项冻结截图细节 |
| 44px 入口必须把状态文字画在图标内 | 入口保持紧凑，通过无障碍标签、可见提示／速览提供状态文字，不强塞小字；不能只靠颜色判断状态 |
| 所有更新等待用户点击 | 阅读／编辑中的重排待用户应用；来源已失效等真实性信息立即标记，不让过期内容继续冒充有效 |
| 推演示例“3–5 位客户” | 仅是生成端的合成建议，不能成为真实会议事实、默认容量或固定业务规则 |

原文建议色值经公式检查后，部分文字配对达不到 4.5:1；第 3 节给出保留方向的调整。没有逐像素还原承诺，不要求后续开发访问原会话才能理解本文。

## 2. 视觉语言

冷白背景、白色内容面、清楚的深色文字、蓝色主要操作和浅色分组构成整体。首页留白较多，会中保持中等密度，来源与推演允许较密但仍用短句、清楚标题和稳定对齐。

先用排版、对齐、分组与间距形成层次，再使用细分隔和局部淡色底。不要把每段文本装成独立卡片或把所有操作都做成主要按钮。业务关系节点可以有容器，但必须表达关系，不是单纯堆装饰。

图标采用统一线宽的线性／轻填充体系，配合文字；产品名称统一为 Agents, Everywhere（Meeting Agent），合成稿里的其他临时标识不成为品牌。首页营销文案、装饰图和图标库仍可细化，不引入自动代办承诺。

主内容、图形和表格使用不透明表面。轻磨砂只用于入口、速览、菜单和可选顶栏；不使用全页玻璃、流光、呼吸或持续动画。浮层失去透明／模糊效果后仍有明确边界。低对比度适用于装饰分隔，不适用于正文和必需控件。

## 3. 建议参数与可读性

这些数值是生成端建议经本地校准后的起点，不是图片测量值。[tokens.json](tokens.json)已迁移为 `collaborative-light-v2`；`src/ui/theme.ts`提供共享颜色变量，宿主 CSS、生成 HTML 和后台渲染检查使用同一份配置。生成器接收 profile、字体与调色板指导；不保证真实模型每次生成的 SVG 均满足审美要求。

### 颜色

| 语义 token | 建议值 | 用法 |
|---|---|---|

| subtleSurface | `#F8FAFD` | 列表表头、次要分组 |
| selectedSurface | `#EEF5FF` | 选中对象的淡背景 |
| textPrimary | `#101828` | 主标题、正文 |
| textSecondary | `#475467` | 次正文 |
| textTertiary | `#667085` | 元信息，保持可读 |
| disabledText | `#98A2B3` | 仅真实禁用态，不用于普通说明 |
| divider / subtleDivider | `#DDE4EE` / `#E9EEF5` | 装饰边界，不直接当作必需控件边界 |
| controlBorder | `#7A8798` | 需要可辨认边界的控件起点 |
| accent | `#2463D8` | 主按钮白字底、普通链接；由原建议 `#2F73F6` 加深 |
| accentDecoration / accentSurface | `#2F73F6` / `#EAF2FF` | 图形强调／淡蓝底 |
| successText / successSurface | `#166534` / `#EAF8F0` | 正常、已确认，另带文字标签 |

| errorText / errorSurface | `#B42318` / `#FDEBEC` | 输入错误、结束相关操作 |

按 sRGB 相对亮度公式计算：原建议 `#2F73F6` 底配白字为 4.28:1，调整后 `#2463D8` 为 5.45:1。原建议绿／橙／红色字配对应淡底分别约 3.28、2.93、3.41:1；本地深色文字配对约 6.51、6.53、5.72:1。只验证这些静态色对，不代表整套界面通过无障碍验收。实际渲染、叠层、禁用／悬停状态和平台材质仍需测试。

### 字体、间距与表面

| 项目 | 建议 |
|---|---|
| 字体 | 优先系统无衬线：`-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif`；不要求安装 Inter 或复制平台专用字体 |
| 标题 | 主标题 28–32px／1.2，组标题 20–24px／1.3；不把生成端 40px 建议作为默认 |
| 正文 | 15px／1.55，重点正文可 17px；说明 13px，标签和时间不小于 12px |
| 字重 | 标题 600，正文 400–500，按钮／状态 500–600 |
| 间距 | 4、8、12、16、20、24、32、40、48、64px；常见内容组距 24–32px、字段距 16–20px |
| 圆角 | 小元素 6px，控件 10px，节点／局部容器 10–14px，浮层 14–18px；不统一套大胶囊 |
| 阴影 | 主内容默认无阴影或 `0 1px 2px rgba(16,24,40,.04)`；浮层建议 `0 8px 24px rgba(16,24,40,.10)` |
| 顶栏／按钮 | 顶栏 56–64px；主按钮高 44–48px，次按钮 36–40px，设置控件 40–44px |
| 列表行 | 最小高 64–72px，允许长标题与文本缩放撑高 |
| 内容宽度 | 1100–1240px 内校准，标准外边距 32px；不为凑满大屏拉宽短文本 |
| 来源抽屉 | 大屏 360–420px；展开后主内容不足 600px 就改覆盖层，不能缩小图中文字 |
| 入口／速览 | 入口约 44×44 DIP，速览约 320px；命中区不能遮挡周围桌面 |

## 4. 页面地图与关键路径

开始前首页、会议工作区和设置是主要视图。空会议、有内容、来源展开、推演展开和结束回看共享工作区，不是五个独立应用模块。首次音频初始化是设置的轻量子流程，桌面入口是独立的低打扰窗口层。

正常路径：启动软件显示轻入口 → 用户打开主窗口 → 首页 → 首次／设备失效时完成音频设置 → 首页一次点击开始 → 连接中 → 收听中的空会议 → 有意义内容自然接管工作区 → 按需来源／推演 → 明确结束 → 释放音源、保存／整理 → 历史回看。

已有活动会议时打开原事件；被暂停时仍保持暂停。打开历史内容、保存设置、关闭工作页均不自动开始或恢复录音。首版仅一场活动采集。

## 5. 八张已生成图片的页面描述

图号按原会话画廊当前顺序。以下是独立可用的文字描述，不需要把业务示例硬编码进组件。

### 图 1 — 开始会议首页

顶部为产品名、设置和轻量菜单。主区域把“开始会议”作为唯一突出动作；旁边低权重显示麦克风、是否收听电脑声音以及更改设置。下面用连续列表行展示最近会议的名称、时间、状态和必要菜单，避免统计卡、人数与完成率。

无活动会议时点击开始直接使用保存的配置；有活动会议时同一位置变成“打开会议”。首次配置缺失进入初始化，不询问每场标题／输出语言。会议标题由内容生成，不要求开始前手填。选历史行进入已结束回看。首页本身不显示收听状态、暂停／结束控件或聊天框。

### 图 2 — 会中核心工作区

轻顶栏显示返回、会议名称、真实采集状态、必要菜单和暂停／继续／结束。主体先呈现当前核心问题，再以动态工作内容说明选择、关系与未知项；近期变化和来源入口居次，“进一步讨论”默认收起。

图中的合成例子是“首批试点应该邀请谁”：内部团队的反馈较快、支持负担较低；受邀客户可验证真实使用但支持容量待确认；关系表达“客户试点取决于支持容量确认”。近期变化为“邀请中需说明是试用”。这只是本次示例；其他会议可用段落、表格、时间线或条件关系，不能固定为两方案卡加中间条件卡。

没有值得表达的新信息时不新增内容。关闭工作窗口保留后台采集；内容生成完成不主动弹出窗口。查看来源、推演和结束都可找到，但不与主内容争夺视觉权重。

### 图 3 — 来源追溯

选中对象在主内容中保持选中态，右侧抽屉说明当前核查的对象。顺序为来源时间、原话、身份可靠性、Agent 理解和纠错入口。例如“声音 A · 身份未确认”说明只是声音分组，不能配上真实姓名或头像。

原话与解释分区显示，翻译不替换原语言。原话纠错与理解反馈不能混为一次无范围编辑，须指向实际来源／对象。抽屉关闭回到原对象、焦点和阅读位置。纠错草稿存在时不因外部点击静默丢失。窄窗覆盖式展示，不把主图挤成小字。

### 图 4 — 主动推演

用户点击“进一步讨论”后，内容附近展开紧凑操作区。用可移除上下文标签说明围绕什么对象、依据什么版本；例如“围绕：受邀客户”“依据：支持容量待确认”。移除标签后实际请求上下文同步改变。

用户提出“如果支持容量不足，有什么替代路径”，结果作为个人工作产物进入页面，标明“个人推演，尚未形成会议决定”。示例可表达缩小试点、先做内部验证等候选路径；不能预填真实容量或默认采纳。避免连续气泡和常驻聊天栏。

收起后保留草稿，更新提示保留阅读位置与选中上下文。依赖内容改变时立即提示依据过期；布局更新按需应用。Enter 发送避开输入法组合，Shift+Enter 换行。

### 图 5 — 收听中的空会议

使用同一顶栏，标题先为“会议 · 日期时间”。设备真实就绪才显示“正在收听”；连接中、仅收到原话、正在整理分别表达。

主区域一句“有值得整理的内容时，会在这里呈现”，有意保留空白。不能出现聊天输入、预留底栏、假波形、假摘要或假人物。若保留小型空状态插图，它只是装饰，不表示已有产物或真实音量。首次有意义内容出现后自然替换空状态，保持页面稳定。

### 图 6 — 音频与语言设置

图中是会中打开设置，顶栏保留真实会议状态。设置分为音频、语言、显示与体验：麦克风选择及真实设备状态、是否同时收听电脑声音、独立的界面语言与会议输出语言、减少透明度／动效。正常运行界面不铺陈 API、token、provider、回放或文字注入开发配置；当前服务未配置时首页有简短连接提示，技术配置说明收在完整设置的“处理详情”中。

保存偏好不开始录音；默认影响下次会议。应用到当前会议必须有明确动作，切换中如实显示缺口。音量指示只能来自正在获授权采集的真实输入或显式测试，不能为美观画假电平。语言跟随系统首选语言：中文系统使用简体中文，其余英文；界面语言选择后立即保存生效，其他偏好仍由保存按钮提交，原话原语言不改。固定界面文字不可拖选，会议内容／原话／输入可选择复制；保留键盘焦点可见性，禁用控件不显示可点击反馈。

### 图 7 — 桌面入口、悬停速览、右键菜单

图片分栏展示三个互斥状态，不把三组窗口同时弹出。收起入口44px，采用[无白边新图标与五态规则](launcher.md)，状态文字通过标签／提示或速览可得。

悬停速览显示当前会议、一个焦点、最多三条变化和打开会议动作。鼠标在入口与速览的联合区域内保持显示，离开后收起，不抢键盘焦点。左键直接打开并持续显示普通工作窗口，无图钉前置步骤。

右键菜单依状态给出开始／打开、暂停／恢复／重连、结束，以及设置／快捷键／退出。活动会议期间不能暗建另一场。打开右键菜单抑制速览；关闭主窗口不停止后台，退出应用时明确处理活动采集。

### 图 8 — 已结束会议回看

复用工作区，顶栏明确“已结束”，无暂停／继续采集操作。保留最后产物、来源与导出；内容按语义区分已确认决定和未决项。合成示例为“已确认：先进行内部试点”“未决：是否邀请客户，等待支持容量确认”。没有确认依据时不能显示已确认。

打开历史只恢复内容。图中的“查看回放”“基于录音”等不构成音频保存／回放功能授权，不能默认实现；使用“基于本次会议已采集内容整理”。结束后仍有已接收内容待整理时，另显示整理进度；保存失败不冒充成功。

## 6. 首次音频初始化：文字补充，尚无设计图

首次无有效配置、指定设备缺失或权限撤回时，通过首页相关入口进入此流程；不在软件启动时静默采集。优先系统默认麦克风，可选择指定设备，电脑声音初始关闭。解释“麦克风：本地发言”“同时收听电脑声音：线上参会者”，不靠猜测运行中的会议软件扩大范围。

页面仅显示设备／权限／可用状态、声音范围、可选“测试麦克风”、保存和取消。没有会中“正在收听”、暂停、结束控件。用户显式点击测试才短暂采集，结束立即释放，测试音频不送入会议。

保存后回首页，不创建会议、不录音。下一次明确点击开始使用配置直接启动；系统授权提示仍可能出现，不能承诺绕过系统流程。取消不留音轨。已有指定设备失效时要求用户重选，不能偷偷换到内置麦克风。

## 7. 组件与信息语义

| 组件 | 规则 |
|---|---|
| 主／次／结束按钮 | 一处主操作，次操作轻量；结束可清楚找到，危险色不用于普通建议；图标按钮有名称、提示、焦点态 |
| 会议列表行 | 标题、时间、状态稳定对齐，整行打开与行内菜单独立可操作，长标题／缩放能撑高 |
| 状态 | 采集状态和理解／保存状态分别展示；颜色、图标、文字共同表达，不用一个“AI 工作中”覆盖所有问题 |
| 来源入口 | 附着实际句子、对象、关系或决定，打开对应证据，关闭恢复触发点 |
| 关系表达 | 节点与连线带可理解语义，继承宿主 token；窄窗改纵向或等价文字，不丢关系 |
| 上下文标签 | 关联事件、对象及版本；可移除，不残留不可见的旧上下文 |
| 更新提示 | 保留当前阅读／草稿；重排待应用，失效标记及时展示 |
| 浮层 | 打开后焦点路径清楚，Escape 关闭最上层并回到触发点，不停止采集 |

原话、Agent 理解、个人推演、个人采纳和会议决定是不同类别，必须有明确标签和来源关系。个人点击采纳不等于会议共识。未确认的负责人、日期、金额和承诺保持未知；确定性计算由可信工具完成。

## 8. 异常与恢复：尚无完整设计图

| 情况 | 应显示与允许操作 |
|---|---|
| 正在连接 | 明示连接中，未收到真实就绪前不能显示收听；防止重复开始 |
| 麦克风缺失／权限失败 | 说明原设备不可用，提供重选／权限指引／重试；保留同一事件 |
| 电脑声音不可用 | 明示缺失通道；用户选择修复或明确仅麦克风继续，不能冒充完整线上声音 |
| 暂停 | 显示已暂停，可明确恢复；打开窗口不会恢复 |
| 采集中断 | 标记输入缺口，保留已有内容，提供重连；不能冒充实时输入 |
| 原话接收正常、理解积压 | 同时显示收听与整理延迟；保留队列／旧产物并说明新鲜度，不把模型问题写成音源失败 |
| 产物依据过期 | 立即指出过期和可用操作，不等用户刷新布局后才告知 |
| 正在结束／后续整理 | 先释放音源；已接收内容继续整理时单独标识，防止重复结束 |
| 保存失败 | 明示哪些内容尚未持久化，保留恢复操作；不得写已成功保存 |

## 9. 尺寸、语言与键盘

1440×1024 允许关系横向组织和来源并排。1024×768 降低外边距、折叠次要说明，依据剩余主内容宽度决定抽屉覆盖。800×600 外边距建议 16–20px，关系改纵向，顶栏次操作进入菜单，结束仍可达。仅确有必要的表格局部横向滚动，页面整体不横向滚动。

200% 文字缩放时允许内容增高和结构改排，不锁死节点／列表高度，不缩小文字硬塞。主标题允许换行，顶栏截断标题时提供可键盘访问的完整标题。中英长文本均需测试，不强制单行按钮。

全部操作需键盘可达，焦点可见。Enter／Space 打开入口；Shift+F10 打开菜单；Escape 关闭最上层浮层。全局显示／隐藏快捷键默认未分配，设置并检查冲突。减少动效关闭不必要的位移、描边和持续动画；减少透明度采用实色底。

目标为普通文字至少 4.5:1，必要控件／图形至少 3:1；静态色对检查只是局部证据，不等于 WCAG 合规结论。系统材质、读屏、焦点、双端和缩放仍待实际验证。

## 10. 工程交接与验收

可信应用外壳负责窗口、导航、采集状态、开始／暂停／结束、设置、列表、来源容器、提问入口、错误和焦点管理。Agent 决定工作内容、关系、布局与必要受控交互，继承同一字体／颜色／间距及来源样式；不得改宿主权限、状态或自行创建另一套外壳。

现有源码入口由[前端规范](../frontend-spec.md)映射；[表达语言](../expression-language.md)和[运行环境](../rendering-runtime.md)定义渲染能力。新风格接入时须连同 CSS、组件、生成器视觉配置及文案统一修改，保护版本／来源／草稿语义。本地实现进度与证据见[本轮记录](../sessions/2026-09-11-frontend-refresh.md)。

验收至少覆盖：首页开始／打开状态、首次初始化、空会议、有内容、来源、推演、会中设置、桌面三态、结束回看和第 8 节异常；在 1440×1024、1024×768、800×600、中英、200% 文字缩放、键盘、减少动效／透明度及 macOS／Windows 分别验证。结果记录到对应 session 和测试结果，不能把概念图当成运行截图。

设计规范阶段完成整体风格、来源校准与静态色对检查。后续[前端实现](../sessions/2026-09-11-frontend-refresh.md)已接入本地运行时并单独验证；原始附件和概念图仍未本地归档。实现依据本文件及专项规范，原图可从来源会话审阅。


## 11. 飞书布局参考后的本地细化

2026-09-11 用户认可当前视觉大致正确，明确要求继续参考飞书云文档、文档正文及多个模块的布局。实际只读观察了飞书云文档列表、文档正文／目录、会议模块与多维表格工作动态；仅借鉴布局，不复制其中私人内容、数据或产品权限。

- 首页保留唯一开始／打开动作；会议列表增加全部／进行中／已结束筛选与标题搜索，空结果可清除筛选。列表使用统一图标、时间与状态对齐。
- 会中采用文档式工作面：顶栏属于会议，次级工具栏属于内容。会议内容、来源、版本具有当前态；导出和可收起内容目录保持低权重。目录由实际生成块构建，点击定位到块，不预设业务章节。
- 来源抽屉标明正在核对的块／行，关联内容用静态标识突出；关闭保留阅读位置与纠错草稿并返回触发点。选中态不改变正文宽度。
- 推演在内容后按需展开，显示可移除的产物上下文和个人性质；未知、待核实、争议维持独立语义。
- 首次／设备失效进入仅音频的轻设置流程；完整设置采用分组导航、局部滚动与固定保存区。技术信息收在处理详情中。保存不开始采音。
- 关系图在窄窗提供等价的起点、关系、终点文字链；桌面图保留稳定节点。两种呈现均可追溯来源。

不新增飞书式永久多模块侧栏、分享权限、协作成员或自动代办。产品仍以一场会议为中心，生成内容的结构由 Agent 决定。
