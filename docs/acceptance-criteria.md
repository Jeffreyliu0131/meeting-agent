# 验收标准：会议事件与Agent生成表达

2026-09-11｜状态：待执行的验收标准，当前没有产品通过结果。业务范围见[产品定义](product-definition.md)，阶段映射见[实施计划](implementation-plan.md)。

## Story Context

参会者启动线上或线下会议事件后，正常讨论即可得到Agent持续生成和修订的简洁工作产物；需要时可以查看、纠正、比较或推演，结束后结果可恢复。语义测试使用合成材料，采音与实际体验另测；不能相互冒充。

## Happy Path

### AC-01：独立会议事件

**Given** 已有一场结束的会议A及其产物。

**When** 用户开始会议B。

**Then** B有独立状态、来源和结果，未被用户选择的A内容不出现在B的理解中。

### AC-02：线下实际输入

**Given** 已告知处理范围并由用户选择一个获授权的麦克风。

**When** 现场多名测试者自然发言。

**Then** 实际收到的内容进入当前事件，音源和身份状态真实可见；漏听、无法区分或听不清的部分不伪造。

### AC-03：线上实际输入

**Given** 一条明确选定并获授权的线上接入路径，远端参会者通过耳机通话。

**When** 本地与远端测试者分别发言。

**Then** 两端内容均能进入事件；测试报告标明平台流或系统采音，不能以仅本机麦克风成功代替。

### AC-04：自主表达选择

**Given** 包含不同对象数量、关系和比较维度的正常讨论，没有预写会议模板答案。

**When** Agent理解这些内容。

**Then** 它生成适合当前用户问题的内容结构，保留实际关系与来源；改变对象和条件后，结构相应改变，不固定映射到样例图。

### AC-05：保持安静与去重

**Given** 现有产物已表达某一观点。

**When** 收到重复输入事件或同一观点的自然复述。

**Then** 重复事件不重复执行；复述可增加独立来源，但不产生同用途的重复产物和无意义通知。

### AC-06：关系、条件与分歧

**Given** 一人支持A，另一段发言提出有条件支持B，身份可以未知。

**When** Agent组织讨论结构。

**Then** A、B及条件和分歧均被保留；系统不会写成一致同意、无条件反对或把不同观点合为一个结论。

### AC-07：已有产物持续修订

**Given** 一个有来源的步骤图已显示某个日期。

**When** 后续发言明确修正该日期。

**Then** 对应对象与产物产生关联修订，旧版可追溯，不新增同用途副本；受影响依赖重新核查或标为过期。

### AC-08：出处追溯

**Given** 一张图中包含会议主张和Agent分析。

**When** 用户查看任一节点或关系依据。

**Then** 能看到对应段落／用户输入／工具结果与内容类型，Agent分析不会被伪装成逐字发言。

### AC-09：主动比较与拆解

**Given** 会议包含两个方案和部分约束。

**When** 用户请求比较或拆解执行步骤。

**Then** 结果使用已知差异和条件，新增分析／步骤标为建议，未知工期与负责人不被补成承诺。

### AC-10：明确关系下的试算

**Given** 明确给定币种、数字和计算关系。

**When** 用户改变一个试算条件。

**Then** 展示可复核计算结果、所用条件及来源，原会议记录不变；还原后回到基础条件。

### AC-11：确认范围

**Given** Agent提出一个方案，尚无会议级确认依据。

**When** 用户采纳为个人方案。

**Then** 仅记录个人采纳，不显示全体同意，也不改写原话。

### AC-12：停止与恢复

**Given** 会话仍在采集并有待处理内容。

**When** 用户明确停止，再关闭和重新打开该事件。

**Then** 采集资源已释放、截止后的输入不被接受；已接收内容可继续整理并明确显示收尾状态，产物和来源能恢复，麦克风不自动重启。

## Edge Cases

### AC-13：身份不足与修正

**Given** 无可靠实名映射或无法稳定区分声音。

**When** Agent记录观点，随后用户修正某段归属。

**Then** 初始以匿名分组或未知展示且基础理解继续；修正保留依据并更新关联内容，不虚构未确认姓名。

### AC-14：跨话题回归

**Given** 讨论从话题A转到B，随后又回到A。

**When** 新发言明确补充A。

**Then** 关联回A已有对象及产物，保留B历史，不只依据最近一句新建重复话题。

### AC-15：时间信息不充分

**Given** 有截止日期，但工期、完成时点或工作日口径缺失。

**When** 用户询问是否来得及。

**Then** 展示已知依赖与具体缺口，不给出无依据的确定日期、关键路径或可行承诺。

### AC-16：旧响应与人工编辑竞争

**Given** Agent正在处理旧版本，而用户已纠正关联内容。

**When** 旧结果返回。

**Then** 已纠正内容不被旧结果覆盖；必要时重算或显示冲突，不悄悄回退。

### AC-17：试算基线变化

**Given** 用户已基于一版方案保存试算。

**When** 会议随后修改了基础条件。

**Then** 原试算仍保留原基线并标明过期，用户可明确选择重新计算，不静默改变既有比较。

### AC-18：转写修订

**Given** 一段转写已经支撑某个观点或数字。

**When** 同一段落的新版本纠正了原文本。

**Then** 引用与依赖随之校验；已有人独立修改的内容不被无条件覆盖，旧引用不继续假装有效。

## Error States

### AC-19：输入或模型断开

**Given** 一场事件正在运行。

**When** 输入或模型服务不可用。

**Then** 显示具体失败环节、最后处理位置和可恢复操作，旧产物仍可查看；输入恢复不重复创建内容，已停止的事件不被重连重新启动。

### AC-20：生成或渲染失败

**Given** 已有一个有效产物。

**When** 新生成内容格式错误、布局无法显示或运行超时。

**Then** 用户仍能看到最后有效版本与更新失败提示，后续讨论处理继续；不存在旧版时以标明的短文字降级，不冒充图形成功。

### AC-21：保存失败

**Given** 用户结束或保存事件。

**When** 存储不可写或发生持久化错误。

**Then** 明确显示尚未保存和可用恢复操作，不显示虚假的保存成功；不为重试而恢复采音。

## Non-Functional Criteria

### AC-22：低打扰与可达性

**Given** 事件保持运行，展示已收起。

**When** 用户悬停、进入浮层、移出、点击固定、键盘打开或关闭。

**Then** 各操作符合预期，移入浮层不误关，固定后不因鼠标离开关闭，隐藏期间仍产生新理解，通知不抢焦点。

### AC-23：工作级可读性

**Given** 三类样例产物分别在实际工作页和速览尺寸展示。

**When** 用户阅读、展开来源并完成“识别焦点／差异／下一步”的任务。

**Then** 无文字溢出、节点遮挡、不可辨文字或无单位图表；关键条件与分歧不丢失，详细解释可按需展开，并记录任务正确率与耗时。

### AC-24：阅读和输入稳定

**Given** 用户正在阅读旧分支或编辑试算参数。

**When** 新产物准备完成。

**Then** 滚动、选择和未提交输入不丢失，不强跳最新内容；不能保持时显示待查看更新，由用户切换。

### AC-25：生成内容无越权

**Given** 含外链、脚本越权、伪造命令、超大图形或无限循环的测试产物。

**When** 系统尝试校验、显示或执行其交互。

**Then** 不能读取密钥、文件、无关会议，不能发起未授权网络／采音／业务写入；超时可终止并恢复可信操作界面。

### AC-26：真实模型而非脚本映射

**Given** 对合成样例更换措辞、顺序、对象数量和条件，并保留可判定语义。

**When** 执行实际模型链路。

**Then** 记录实际模型结果与来源；失败如实计入，不以固定关键字生成预写产物替代。

### AC-27：性能与成本可解释

**Given** 代表性测试输入、设备与网络条件均有记录。

**When** 测量接收、理解、生成、渲染与展开过程。

**Then** 各段时延、样本量、调用与token用量分别报告，并与技术设计目标比较；未测或未达标不能标为通过。

## Notes

- 人物准确率分别记录已显示归属中的正确／错误、未知数量、可归属覆盖率；声音分组与实名映射分开。当前未设通过阈值，须用实际结果和错误代价校准。
- 三段合成讨论不是充分的泛化或体验证据。至少追加未用于提示词调优的变体与真实多人音频。
- 声称某carrier完成必须有该载体的语义、渲染、更新、来源与操作测试。没有交互的SVG通过不代表HTML交互完成。
