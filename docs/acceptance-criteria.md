> 文件职责：产品／工程设计要求，不是完成清单。当前进度与最新修订见[状态页](status.md)；已交付首版取舍见[ADR-003](adr/003-cross-platform-first-version.md)，实际结果见[验证记录](../tests/results/README.md)。具体实现以代码核对，未实现的要求仍是目标。
2026-09-11｜状态：产品验收标准；已执行与未执行按对应版本的验证记录区分，不在本文件宣称全部通过。业务范围见[产品定义](product-definition.md)，阶段映射见[实施计划](implementation-plan.md)。

## Story Context

参会者启动线上或线下会议事件后，正常讨论即可得到Agent持续生成和修订的简洁工作产物；需要时可以查看、纠正、比较或推演，结束后结果可恢复。语义测试使用合成材料，采音与实际体验另测；不能相互冒充。

## Happy Path

### AC-01：独立会议事件

**Given** 已有一场结束的会议A及其产物。

**When** 用户开始会议B。

**Then** B有独立状态、来源和结果，未被用户选择的A内容不出现在B的理解中。

### AC-02：线下实际输入

**Given** 已告知处理范围并由用户选择一个获授权的麦克风。

**When** 现场多名测试者自然发言。

**Then** 实际收到的内容进入当前事件，音源和身份状态真实可见；漏听、无法区分或听不清的部分不伪造。

### AC-03：线上实际输入

**Given** 一条明确选定并获授权的线上接入路径，远端参会者通过耳机通话。

**When** 本地与远端测试者分别发言。

**Then** 两端内容均能进入事件；测试报告标明平台流或系统采音，不能以仅本机麦克风成功代替。

### AC-04：自主表达选择

**Given** 包含不同对象数量、关系和比较维度的正常讨论，没有预写会议模板答案。

**When** Agent理解这些内容。

**Then** 它生成适合当前用户问题的内容结构，保留实际关系与来源；改变对象和条件后，结构相应改变，不固定映射到样例图。

### AC-05：保持安静与去重

**Given** 现有产物已表达某一观点。

**When** 收到重复输入事件或同一观点的自然复述。

**Then** 重复事件不重复执行；复述可增加独立来源，但不产生同用途的重复产物和无意义通知。

### AC-06：关系、条件与分歧

**Given** 一人支持A，另一段发言提出有条件支持B，身份可以未知。

**When** Agent组织讨论结构。

**Then** A、B及条件和分歧均被保留；系统不会写成一致同意、无条件反对或把不同观点合为一个结论。

### AC-07：已有产物持续修订

**Given** 一个有来源的步骤图已显示某个日期。

**When** 后续发言明确修正该日期。

**Then** 对应对象与产物产生关联修订，旧版可追溯，不新增同用途副本；受影响依赖重新核查或标为过期。

### AC-08：出处追溯

**Given** 一张图中包含会议主张和Agent分析。

**When** 用户查看任一节点或关系依据。

**Then** 能看到对应段落／用户输入／工具结果与内容类型，Agent分析不会被伪装成逐字发言。

### AC-09：主动比较与拆解

**Given** 会议包含两个方案和部分约束。

**When** 用户请求比较或拆解执行步骤。

**Then** 结果使用已知差异和条件，新增分析／步骤标为建议，未知工期与负责人不被补成承诺。

### AC-10：明确关系下的试算

**Given** 明确给定币种、数字和计算关系。

**When** 用户改变一个试算条件。

**Then** 展示可复核计算结果、所用条件及来源，原会议记录不变；还原后回到基础条件。

### AC-11：确认范围

**Given** Agent提出一个方案，尚无会议级确认依据。

**When** 用户采纳为个人方案。

**Then** 仅记录个人采纳，不显示全体同意，也不改写原话。

### AC-12：停止与恢复

**Given** 会话仍在采集并有待处理内容。

**When** 用户明确停止，再关闭和重新打开该事件。

**Then** 采集资源已释放、截止后的输入不被接受；已接收内容可继续整理并明确显示收尾状态，产物和来源能恢复，麦克风不自动重启。

## Edge Cases

### AC-13：身份不足与修正

**Given** 无可靠实名映射或无法稳定区分声音。

**When** Agent记录观点，随后用户修正某段归属。

**Then** 初始以匿名分组或未知展示且基础理解继续；修正保留依据并更新关联内容，不虚构未确认姓名。

### AC-14：跨话题回归

**Given** 讨论从话题A转到B，随后又回到A。

**When** 新发言明确补充A。

**Then** 关联回A已有对象及产物，保留B历史，不只依据最近一句新建重复话题。

### AC-15：时间信息不充分

**Given** 有截止日期，但工期、完成时点或工作日口径缺失。

**When** 用户询问是否来得及。

**Then** 展示已知依赖与具体缺口，不给出无依据的确定日期、关键路径或可行承诺。

### AC-16：旧响应与人工编辑竞争

**Given** Agent正在处理旧版本，而用户已纠正关联内容。

**When** 旧结果返回。

**Then** 已纠正内容不被旧结果覆盖；必要时重算或显示冲突，不悄悄回退。

### AC-17：试算基线变化

**Given** 用户已基于一版方案保存试算。

**When** 会议随后修改了基础条件。

**Then** 原试算仍保留原基线并标明过期，用户可明确选择重新计算，不静默改变既有比较。

### AC-18：转写修订

**Given** 一段转写已经支撑某个观点或数字。

**When** 同一段落的新版本纠正了原文本。

**Then** 引用与依赖随之校验；已有人独立修改的内容不被无条件覆盖，旧引用不继续假装有效。

## Error States

### AC-19：输入或模型断开

**Given** 一场事件正在运行。

**When** 输入或模型服务不可用。

**Then** 显示具体失败环节、最后处理位置和可恢复操作，旧产物仍可查看；输入恢复不重复创建内容，已停止的事件不被重连重新启动。

### AC-20：生成或渲染失败

**Given** 已有一个有效产物。

**When** 新生成内容格式错误、布局无法显示或运行超时。

**Then** 用户仍能看到最后有效版本与更新失败提示，后续讨论处理继续；不存在旧版时以标明的短文字降级，不冒充图形成功。

### AC-21：保存失败

**Given** 用户结束或保存事件。

**When** 存储不可写或发生持久化错误。

**Then** 明确显示尚未保存和可用恢复操作，不显示虚假的保存成功；不为重试而恢复采音。

## Non-Functional Criteria

### AC-22：低打扰与可达性

**Given** 事件保持运行，展示已收起。

**When** 用户悬停、进入浮层、移出、点击固定、键盘打开或关闭。

**Then** 各操作符合预期，移入浮层不误关，固定后不因鼠标离开关闭，隐藏期间仍产生新理解，通知不抢焦点。

### AC-23：工作级可读性

**Given** 三类样例产物分别在实际工作页和速览尺寸展示。

**When** 用户阅读、展开来源并完成“识别焦点／差异／下一步”的任务。

**Then** 无文字溢出、节点遮挡、不可辨文字或无单位图表；关键条件与分歧不丢失，详细解释可按需展开，并记录任务正确率与耗时。

### AC-24：阅读和输入稳定

**Given** 用户正在阅读旧分支或编辑试算参数。

**When** 新产物准备完成。

**Then** 滚动、选择和未提交输入不丢失，不强跳最新内容；不能保持时显示待查看更新，由用户切换。

### AC-25：生成内容无越权

**Given** 含外链、脚本越权、伪造命令、超大图形或无限循环的测试产物。

**When** 系统尝试校验、显示或执行其交互。

**Then** 不能读取密钥、文件、无关会议，不能发起未授权网络／采音／业务写入；超时可终止并恢复可信操作界面。

### AC-26：真实模型而非脚本映射

**Given** 对合成样例更换措辞、顺序、对象数量和条件，并保留可判定语义。

**When** 执行实际模型链路。

**Then** 记录实际模型结果与来源；失败如实计入，不以固定关键字生成预写产物替代。

### AC-27：性能与成本可解释

**Given** 代表性测试输入、设备与网络条件均有记录。

**When** 测量接收、理解、生成、渲染与展开过程。

**Then** 各段时延、样本量、调用与token用量分别报告，并与技术设计目标比较；未测或未达标不能标为通过。

### AC-28：跟随系统与完整双语界面

**Given** 新安装应用，分别使用中文、英文及其他系统语言；另有已保存手动语言偏好的应用。

**When** 用户开始、查看、暂停、结束会议并打开菜单／设置，在设置中切换跟随系统或手动语言。

**Then** 新安装中文系统默认简体中文、其他系统默认英文，手动偏好优先且重启保留；两种locale的固定文案、错误、菜单和无障碍标签完整。选择界面语言后无需另点保存即可生效，重开设置／重启保留选择，其他设置草稿不被提交或丢失；写入失败保持旧语言并就地提示。系统首选语言与应用locale／地区格式不同时按系统首选语言解析。切换界面语言不停止采集、不重写活动会议输出，原始发言保留；主页面与独立右键项无常驻语言切换。

### AC-29：输出语言切换与旧任务

**Given** 英文产物正在生成，期间用户切换为中文输出并修改了相关条件。

**When** 旧英文任务及新中文任务先后返回。

**Then** 可见新产物符合当前语言与条件；旧任务不能覆盖，来源和对象ID保持关联，翻译不新增会议事实。

### AC-30：中英输入与原文

**Given** 中文、英文及混说测试会议，包含否定、条件、人数和日期。

**When** 生成任一目标语言的纪要与图形，再查看来源翻译。

**Then** 限定词、数字、日期和分歧保留，原文不被译文替代；真实音频结果与合成文本结果分别记录。

### AC-31：桌面图标与持久工作页

**Given** 软件运行且有一场正在采集的事件。

**When** 悬停、移入速览、移出、左键打开、重复点击、拖动入口以及关闭工作页。

**Then** 速览按联合区域显隐，点击复用并聚焦工作页，拖动不误触打开；关闭工作页后台继续，透明空白区域不阻挡其他应用。

### AC-32：菜单与快捷键

**Given** 事件分别处于未开始、采集中、暂停、错误和结束过程中。

**When** 右键或用键盘打开菜单、执行对应操作、设置冲突快捷键。

**Then** 菜单与状态一致且无重复启动；菜单关闭不造成焦点丢失；冲突可见，不吞系统键，不因Escape或普通关闭而结束采集。

### AC-33：克制材质与回退

**Given** 入口／菜单覆盖明亮、暗色或复杂桌面背景。

**When** 启用减少透明度、减少动效，或在不支持材质的环境运行。

**Then** 外围正确退回实色和无非必要动画，正文与图表始终清楚，内容和操作不丢失；记录对比和资源表现，不以动态效果强行换取视觉质感。

### AC-34：选定设计与自由生成共存

**Given** 实现工作页按[当前风格与页面规范](design/style.md)中的已认可 8 图方向构建，建议参数经过可读性校准。

**When** Agent生成关系图、表格、SVG及组合内容，并在目标窗口尺寸和200%缩放查看。

**Then** 外壳保持选定层级、字阶与导航，内容结构随会议需要改变；没有硬编码概念图的业务布局，无遮挡、不可读文字或强制全屏／置顶。

### AC-35：中文输入法与非打扰更新

**Given** 用户正在用中文输入法组合文字或编辑试算输入。

**When** 按Enter选择候选字，或此时收到语言／内容更新。

**Then** 不误发送，未提交内容和焦点保留；真正发送仍需完成输入后触发，更新不抢焦点或丢失草稿。

## 连续 Agent 补充验收

- LIVE-01：普通打开工作页时自动更新；提问草稿不冻结页面，个人试算维持基线，选中文字不被替换。
- LIVE-02：理解提交不等待独立生成／预览；连续输入能推进已处理来源，相关纠正使旧表达失效。
- LIVE-03：慢STT进入有界队列，溢出／失败记录缺口并继续采集；不同音轨按采集时间而非返回先后组织。
- LIVE-04：长会检索回到旧条件，未处理原话不静默裁剪；预算限制保留输入，失败和过期调用仍计入账目。
- LIVE-05：正常入口一次设置后连续两场一键开始；有内容才出现探索入口，手工命名不被Agent覆盖，失效设备恢复不复制会议。

程序层结果见 [本轮验证](../tests/results/live-agent-validation.md)。实际语义、真实时延、成本和音频质量必须另外测量。

| UI-02 | 打开内容目录并选取生成块、查看该块或行来源 | 导航来自实际块；来源显示核对目标；关闭回到触发点，不跳到无关内容 |
| UI-03 | 在同一会议编辑来源纠错并关闭／重开抽屉，或收起／展开推演 | 当前UI会话草稿保留；移除产物上下文后请求不残留该显式引用；不承诺跨重启草稿恢复 |
| UI-04 | 首次音频配置及完整设置分别在800×600、200%缩放下使用 | 首次仅音频且保存不采音；完整设置的字段可滚动到并实际操作，短视口不被固定页头／页尾挤没 |
| UI-05 | 更新本地应用并打开旧历史 | 实际应用显示新视觉且历史保留；以包内容／启动结果区分源码构建、安装包更新和真实采音验收 |


### UI-06：桌面入口外观与状态一致性

在深／浅背景核对44 DIP入口无白色常驻描边和不透明窗口底角；依次投影待命、连接、采集、暂停与错误，tooltip、无障碍名称、速览与标记一致。连接未就绪不得绿灯，服务失败必须覆盖旧绿灯，模型整理不改变真实采集状态。合成快照／音源验证与真实设备证据分开。


## Agent 可靠性补充验收

| 编号 | 场景 | 通过条件 |
|---|---|---|
| REL-01 | 有条件提议、负责人／日期、后续承诺 | conditionIds 指向约束；原话引用和值可核查；旧依据不能取消条件；committed 不等于会议共识 |
| REL-02 | 个人试算后继续自然发言 | 后台理解与表达上下文均无个人请求／产物／试算；会议确认拒绝个人与混合来源 |
| REL-03 | 很久后回到旧限制，或上下文超限 | 有效条件和会议决定证据保留；必要记忆超限明确停止，不静默裁掉 |
| REL-04 | 原话纠正或依赖条件更新 | 受影响事项和产物待核对；修订不抢写结论，保留旧对象；新证据才可解除待核对 |
| REL-05 | 结束、尾部转写、失败及重启 | 核对全场待处理来源、分歧、条件、任务缺项、过期内容和输入缺口；按会议计数；恢复不采音 |
| REL-06 | 会后回看与查看依据 | 结束核对和汇总记录可展开，来源可打开；中英同义；个人假设不进入汇总会议记录 |

定义与限制见[可靠性规范](agent-reliability.md)。程序测试不代替真实模型语义评价。


界面细节补充：固定外壳文字拖选不产生选区，会议正文／原话／输入框仍可选择复制；弹窗Tab不落入折叠诊断或禁用控件，焦点环可见，窗口尺寸与200%缩放下语言控件可用。
