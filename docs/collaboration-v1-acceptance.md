# 首版会议协作：验收场景与实施门槛

状态：完整验收目标；本轮实际覆盖和未验证项见[验证矩阵](../tests/results/collaboration-v1-validation.md)。版本：`collaboration-v1 / design-1`。

依据：[产品／图设计](collaboration-v1-design.md)、[数据契约](collaboration-v1-contracts.md)。测试使用独立临时会议库、明确标记的模拟身份及合成内容。真实模型测试与真实音频测试分开记录，不触碰日常会议替代测试库。

## 1. 首版主路径

合成会议“试点上线安排”：host与A／B／C四个身份，host默认不参与投票。先手工开启协作模拟，参与者逐窗打开。

1. host准备投票：“接下来讨论上线方案”；发言依次给出内部试点、邀请客户、直接开放，并加入一段无关讨论。
2. 草稿只收集相关选项；host修改“邀请客户”为“邀请五位客户”，后续语音不抢写手工字段。
3. host停止收集，等冻结范围处理完，预览题目、选项和受众A/B/C后发放。三个参与者看到相同版本，各自提交；B修改一次选择。
4. host截止；统计以每人最后一次有效票为准，未显示过开放期领先项。host选择方案，再准备分工草稿。
5. 分工让A做页面、B做接口；B已有一个明确独占时间区间的任务，新任务重叠。R2产生有证据冲突，host看到行内标记和私有冲突草稿。
6. host展示分工和冲突；B补充可用时间；host选择调整方案，查看字段diff并发布替代分工。旧轮回应不迁移。A/B分别接受新任务。
7. host基于新分工发出决定确认，required=A/B/C；C选择有保留，必须提供说明。该回应触发R分析，不能记录决定。
8. 条件澄清后发布新的确认版本；A/B/C逐人重新同意。host记录此范围决定，保存对同一版本的回应依据。
9. 结束会议；所有开放轮截止，原话尾部可补充但不能再发组件；重启后保留组件、回应、决定与来源，不采音。

判定：全过程任何时候都能区分Agent建议、host发放、个人回应、指定范围决定。录像／截图和事件轨迹中的componentId、publishedRevision、actorId能互相对照。

| CON-05 | 关闭冲突卡但条件未变化 | 卡closed，冲突仍unresolved |
| CON-06 | 本人撤回问题／接受相关修订 | R核对后可resolved，历史证据保留 |
| CON-07 | 试图发放包含非共享个人理由的卡 | SOURCE_NOT_SHAREABLE或显式披露步骤，参与者看不到私有内容 |

| DEC-06 | 已记录后新异议 | 新问题／待复核，旧决定不可变 |
| DEC-07 | 异议已保存但R未完成；或点击时final尚待M处理 | 分析／来源前沿门槛阻止记录，不能发生“先记录再发现已有反对” |

## 4. 工作流唤起与成本测试

| ID | 场景 | 预期图／节点轨迹 |

## 6. 界面与双端检查

四组件分别检查host编辑／ready／发放、participant未回应／提交中／失败／已提交、closed／cancelled／superseded、依据过期、空字段、长标题和来源展开。至少覆盖360px宽参与者窗口、200%缩放、中文输入法、键盘完成所有操作、屏幕阅读状态文本。

Windows与macOS分别检查独立角色窗口、IPC投影、回到焦点、窗口关闭重开、无自动采音及字体可读性；程序截图不能代替另一平台实机结论。主题和生成表达保持已有视觉一致性，不对全部交互都加高亮／动画。

## 7. 模型语义评估与发布门槛

建立至少60条人工标注的多轮合成对话（中文≥40，英文／中英混合≥20），覆盖四类意图、负例、引用／否定、准备态、目标歧义、改口、同名、跨话题返回、冲突证据不足。训练示例与验收对话分开，评估冻结模型ID、prompt、schema、源码版本；不以关键词命中率代替多轮行为正确率。

指标分别记录：family／operation分类macro-F1、目标组件定位准确率、关键字段与来源正确率、无依据字段比例、持续收集误纳率、冲突supported精确率、草稿响应时延及每根事件调用／token。建议首版门槛：分类macro-F1≥0.90、明确目标定位≥0.95、关键字段／来源正确率≥0.95；同一冻结验收集不允许出现自动替人回应／发放／记录决定，也不允许编造负责人或日期而不标未知。这些是目标，尚无实测值。

可信权限、计数、版本、幂等与状态迁移用确定性测试保证；即使模型分类得分高也不能替代这些检查。真实供应商评估须实际执行并人工核查，模拟模型通过不等于真实模型通过。语义指标未达标时保留手工准备路线，自动提案标记实验性，不能宣称首版自动闭环验收完成。
