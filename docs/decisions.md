## 已确认产品方向

| ID | 内容 | 本轮依据 |
|---|---|---|

## 被修正的旧理解

| 旧理解 | 当前解释 |
|---|---|
| 预算筹备会作为核心业务 | 预算只是一个可验证推演例子 |
| 主持人发布，其他人才能看见 | 默认个人按需查看；共享可扩展 |
| 所有场景必须准确实名后才可用 | 身份分层，未知时仍维护观点与分歧 |
| 固定视图或组件填数 | Agent负责表达规划、生成与持续修订 |
| 任意生成全部后置 | 通用应用生成可后置；会议工作表达生成必须实现 |
| 只有Zoom或电脑远程会议 | 线下输入同样是产品需求 |

外部技术设计v0.1仅为参照，其版本／去重／来源／试算机制可借鉴；预算领域模型、主持人共享舞台和未核验赛程不能成为当前依据。本目录未复制外部文件，也不依赖它才能实现。

## 工程建议，尚非已验证选型

- TypeScript＋Electron＋React，可信本机会话服务，SQLite持久化；见[ADR-001](adr/001-local-session-service.md)。
- 表达描述、图语言、SVG、图表规范与受控HTML组合；见[ADR-002](adr/002-generative-expression-runtime.md)。
- 初期顺序工作流与有界修复，不强制LangGraph或多Agent。
- 先验证一套实际演示桌面系统；未指定必须Windows或必须macOS。
- 线下单采集设备、个人本地会话服务优先；多人共享需要额外服务，不默认随桌面首版实现。
- 性能阈值、输入与产物大小上限、保留策略初值均属可测试参数，不能写成实测效果。

## 尚需实际验证

目标演示机与系统版本、系统采音、平台账号权限、模型与语言质量、声音分组和姓名映射、HTML隔离与性能、真实时延、使用成本、团队分工、官方比赛规则及提交要求。

文档完成不等于这些事项完成；不从建议的开发阶段推导真实工时。后续采用或更换技术选型时追加依据和测试结果，不回改用户已确认的产品目标。
