# 实施与交接计划

2026-09-11｜当前只完成文档、测试材料和目录准备。下轮收到产品开发请求后执行本计划。阶段是建议顺序，不是已核验工时、比赛赛程或团队分工。

## 1. 先建立可验证的最小闭环

首个开发切片：**一场事件 → 合成段落输入 → 实际模型理解与表达规划 → 生成一个合适产物 → 追加发言后正确修订 → 原话追溯与保存恢复**。

这不是固定样例页面。必须改变措辞、对象和关系后仍由模型生成表达。合成内容让我们先隔离状态与生成问题；真实采音在下一阶段独立验证。

## 2. 阶段与完成边界

| 阶段 | 实现内容 | 出口证据 | 仍不能声称 |
|---|---|---|---|
| P0 环境与风险核验 | 选实际演示系统；麦克风／线上输入候选、模型权限、独立表达宿主探针；建立最小构建与测试工具 | 可复现命令、环境版本、成功／失败记录；更新ADR与README | 产品已完成、所有平台支持 |
| P1 事件与生成核心 | 状态／来源／版本；合成段落；实际模型；短文本、表格、关系图、SVG；校验、修订、保存 | 三类样例中适用语义通过；真实生成内容；冲突与恢复检查 | 真实会议接入、全部交互载体 |
| P2 实时输入与桌面入口 | 线下实际采音；线上一条可用路径；未知身份；悬停、固定、收起持续处理；停止释放 | 线下多人＋远端耳机双向测试；运行录屏与资源状态 | 未测系统或平台、可靠实名识别 |
| P3 交互表达与推演 | 数据图表、受控HTML；比较／拆解；独立Scenario；确定性工具；可信确认 | 已启用载体的更新／来源／交互／越权测试，计算及基线隔离 | 任意完整应用生成、自动多人共识 |
| P4 整体验证与交付 | 全部标准、变体输入、性能与成本、工作级表达校正；独立启动与打包说明 | 实际结果、已知限制、可复现演示与交付清单 | 未验证效果、未获授权的公开发布 |

P0只做风险探针，不先搭大型平台。核心模型调用、输入采集和代码渲染三个探针各自标结果；任何一项失败不能靠录屏回放掩盖。P1中的固定合成段落不自动满足P2。

如果时间不足，交付明确阶段版本和未完项；不能偷偷删除生成式表达或线上／线下范围。SVG、图语言和HTML不是必须同时先写，但载体覆盖应在README中准确列出。

## 3. 代码归属与接口先后

具体目录职责见[src说明](../src/README.md)。建议先定义共享schema和业务规则，再实现输入与模型适配、可信宿主，最后完善视觉样式。

| 工作包 | 对应目录 | 优先接口 |
|---|---|---|
| 共享契约 | `src/contracts/` | Segment、对象、关系、ExpressionPlan、ArtifactRevision、命令 |
| 状态和工具 | `src/domain/`、`src/service/` | ingest、execute、snapshot、scenario、jobs、持久化 |
| Agent | `src/agent/` | interpretBatch、plan、generateArtifact、validate、repair |
| 实际输入 | `src/integrations/` | start／stop、段落修订、音源与身份状态 |
| 表达 | `src/renderers/` | 多carrier适配、预览、绑定、更新、dispose |
| 桌面 | `src/desktop/` | 生命周期、可信UI、窗口、IPC、低打扰入口 |

不以图形位置作为业务身份，不把生成HTML内部state作为会话数据库，不在renderer保存密钥。

## 4. 下一轮技术核验点

- 演示设备的系统／版本、麦克风、耳机、系统采音与窗口能力；当前没有指定必须Windows或macOS。
- 模型账号确实可用，结构化输出和实际延迟符合需要；没有key时如实标注模型未接，不静默用假输出。
- 图语言、SVG、chart和HTML运行环境的兼容版本；在开发安装后记录lockfile与构建结果。
- Electron内的独立表达WebContents和资源终止是否能隔离异常脚本；未证明前不启用任意生成JS。
- 真实场景所需的网络、平台额度和音源权限，尤其本机路线能否收到远端声音。

上述核验是工作内容，不要求用户逐项重复批准。只有涉及新增购买、权限变更、外部部署或实质范围变化时再按授权规则处理。

## 5. 验收输出

每个阶段更新README真实运行方法、已实现载体／平台、已知限制；将真实结果放入`tests/results/`。结果必须区分：静态文档检查、确定性单元测试、实际模型语义、真实音频、桌面交互与多人共享。

只有相关检查全部执行才标通过。没有实际模型就不能报Agent生成完成；只有浏览器截图不能报桌面悬浮完成；仅在本地验证不能报云端上线。
