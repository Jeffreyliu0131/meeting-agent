# Session 标题

记录类型：本任务执行记录／观察记录／历史证据补录（三选一）。
状态：进行中／完成／部分完成／阻塞。更新时间：日期、时间和时区。
关联任务：可选任务标题／ID，仅作辅助定位。

## 目标与授权

填写当前请求要解决的问题、允许修改的范围，以及明确不包含的外部操作。

## 接手基线

填写读过的状态与相关交接、Git HEAD、已有未提交改动及并行工作边界。不要把他人代码归为本轮完成。

## 实际变化与依据

填写本轮已完成的变化、相关文件链接、用户确认或工程取舍及依据。进行中与只写规范要明确。

## 验证与未验证

填写实际命令／方法、时间、环境、代码基线／工作树范围、结果及证据链接。没有执行就写未执行；若代码随后变化，注明原结果适用范围。

## 未完项与下一步

填写卡点、恢复入口、建议顺序与必要前置条件。下一步是建议，不自动授予外部操作权限。

## 文件同步与交付

填写同步的状态／索引／正文／目录说明，以及检查结果。Git 提交／推送／部署按实际填写，不把草稿或本地修改写成已交付远端。
