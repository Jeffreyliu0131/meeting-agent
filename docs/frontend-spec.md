## 2. 页面与组件地图

| 页面／组件 | 默认内容与主操作 | 退出与状态 |
|---|---|---|
| Meeting library | `Start meeting`、当前事件、历史事件；无事件时一个空状态 | 打开事件进入工作页；不自动采集 |
| Start meeting | 使用保存的音频设置直接开始；标题由Agent命名，语言自动解析 | 一次意图衔接创建与采集；首次设置／异常按需处理，取消不留音轨 |
| 首次音频初始化（尚无设计图） | 设备／权限状态、麦克风、电脑声音范围、显式测试、保存／取消 | 无会中顶栏；保存返回首页但不录音，测试结束释放设备 |
| Meeting workspace | 顶栏、生成工作区域、变化提示；有内容后出现轻提问入口，点击才展开；来源抽屉默认关闭 | 关闭窗口回桌面入口；不会停止正在运行的事件 |
| Desktop launcher | 可贴边的小图标、真实运行标记 | 悬停速览、左键打开、右键菜单、拖动定位 |
| Hover preview | 当前会议的 Agent 画板、实时生成状态；无会议时显示会议入口 | 离开联合区域后收起；来源和主动操作转到工作页 |
| Context menu | 按事件状态提供操作 | Escape、外部点击或执行操作后关闭 |
| Source drawer | 原话、来源时间／身份状态、翻译入口、纠错入口 | 关闭返回原内容选择与滚动位置 |
| Settings | 音频设备与电脑声音、跟随系统／手动语言、视觉辅助、快捷键 | 全局音频偏好影响下次会议；应用到当前会议需明确操作；语言规则单独说明 |
| Ended event | 原工作页进入已结束状态，保留产物、决定、未决项和导出 | 重新打开不恢复采音 |

应用导航控制固定，工作内容结构不固定。不能把选定图中的对照表、依赖图和“Latest change”设计成每场会议必须填满的三张卡片。

## 3. 会中工作页的布局契约

本节会中布局已按2026-09-12用户确认的[正文／窄原话边注](design/meeting-editorial.md)修订，参考图是合成概念，运行证据单独记录。

### 顶栏

高度建议56–64 CSS px；从左到右为返回Meetings、事件名称、真实状态，右侧为设置／事件菜单、Pause／Resume与End meeting；语言只在设置中管理。空间不足时次要操作进入菜单，结束会议仍可清楚找到。

系统原生窗口控制保留，应用控件避开系统拖动区域。工作页是正常可移动／缩放窗口，默认不全屏、不强制置顶、不覆盖其他应用；只有轻量入口和临时浮层采用必要的置顶行为。

### 主工作区

参考视口1440×1024；宽屏主内容在左，原话栏360–380px约占25%，常规正文外边距48px，1100–1250宽用32px，窄窗20–28px。正文不设外层圆角卡片。标题30px、组标题17px、正文15px；不照抄概念图中过大的标题。

每次优先一个主问题及其生成内容，允许必要的辅助表达。旧话题通过历史／话题导航按需访问，无永久宽侧栏，无自动无限卡片墙。Agent可以生成组合内容，但应遵守同一视觉规范。

### 来源与详情

默认显示来源轻入口，点击编号打开精确ID／revision。宽≥1100px保留360–380px原话区域，开关不改变正文横向位置；窄窗改覆盖层，关闭恢复主视图及焦点。面板通常位于会议顶栏下；窄窗且有效高度≤500px时使用全高模态以保留阅读空间，关闭恢复会议控制。纠错草稿在同一会话中保留。

### 提问入口

空会议、只有原话或处理占位时不显示提问框。出现有意义的Agent文字或图形后，在内容附近提供轻量入口，用户点击才展开；当前实现在生成内容及可信操作后提供“进一步讨论”，已有本地合成界面与桌面测试；最终用户场景质量仍需反馈。选中对象时附可移除的上下文标签，并关联产物／对象版本。用户发问后结果优先成为工作产物，不扩展为大段聊天流。Shift+Enter换行，Enter发送必须避开输入法组合状态。点击Send明确触发同样操作。

仅在用户展开后为提问区域预留空间，收起和空状态不保留空白底栏。区域不挡内容，实时更新保留焦点、草稿与上下文版本；模型处理中可继续阅读。普通会议不提供常驻文字来源注入，原话纠错保留在来源抽屉。

### 尺寸与缩放

至少设计验证1440×1024、1024×768、800×600工作窗口及200%文本缩放。宽度不足时先隐藏次要导航、折叠抽屉、换行控件；表格确需横向滚动时只滚表格区域。不得将整张图等比缩到文字不可读。

## 4. 桌面入口的状态机

展示状态：`collapsed | peek | workspace_open`；菜单状态`closed | open`独立。此前文档中的pinned统一解释为左键打开并持续显示工作页，不要求再点一次图钉才能保持打开，也不代表系统always-on-top。

| 输入／情境 | 必须行为 |
|---|---|
| 启动软件 | 按保存偏好显示／隐藏入口，不自动录音；恢复事件内容不等于恢复采集 |
| 悬停入口 | 停留250ms显示当前会议画板，不激活其他应用焦点；工作页正聚焦、拖动或提醒气泡期间抑制 |
| 鼠标进入速览 | 保持显示；图标与浮层间的间隙也纳入关闭宽限 |
| 离开入口与速览整体区域 | 建议300ms后收起；返回区域取消关闭 |
| 左键点击入口／速览打开操作 | 打开当前事件工作页并保持；无当前事件则打开会议列表和开始入口 |
| 工作页已经打开时再点击 | 聚焦现有窗口，不创建副本、不重新录音 |
| 右键入口 | 打开菜单并关闭／抑制速览，直到菜单退出 |
| 拖动入口 | 位移超过6px后取消待展开速览并抑制悬停，不触发点击；结束时贴边，重新进入后才可速览 |
| 关闭工作页 | 隐藏至入口，后台继续；不误发stop命令 |
| End meeting | 执行结束流程并立即显示Ending；音源释放后Ended，已接收内容仍整理则额外标Finishing notes |
| Quit且有进行中的事件 | 在可信确认中说明将结束采集并退出；取消则继续运行 |

2026-09-12用户要求悬停直接看到 Agent 画板，替代旧的“一个焦点＋最多三条变化”内容限制。速览复用当前活动会议最新 meeting-scope 产物渲染、来源编号和实时快照，保留文字、表格、图形及真实生成状态；个人推演与历史会议不自动混入。无产物时显示真实等待状态，不填充示例内容。画板采用可滚动、不透明的正文面，默认760×560 DIP，按入口所在显示器可用空间缩小，左右择宽展开且不覆盖入口；无活动会议回到340×240紧凑入口。数字为实施参数，实际验证见[本轮记录](sessions/2026-09-12-hover-canvas.md)。

鼠标离开隐藏的只是速览，不隐藏已打开的工作页，不停止后台更新。再次悬停呈现最新修订。来源点击在工作页打开对应产物版本和原话；建议动作只在工作页准备问题草稿，用户发送后才执行。后台生成完成不自动弹出工作页。

图标建议44×44 DIP，位置记录相对display工作区，拔插显示器后钳制到可见边界。原生窗口命中区贴合实际入口／浮层，透明空白区域不能挡住其他软件。不能声称覆盖所有系统安全界面或独占全屏；目标系统需测试。

## 5. 右键菜单与快捷键

| 状态 | 菜单项 |
|---|---|
| 无活动事件 | Start meeting、Recent meetings |
| capturing | Open meeting、Pause capture、End meeting |
| paused／input_error | Open meeting、Resume capture（来源有效时）／Reconnect input、End meeting |
| draining | Open meeting；显示Ending，禁止重复开始／结束 |
| 通用组 | Keyboard shortcuts、Settings、Quit |

语言统一在Settings中管理，默认跟随系统；Interface language与Meeting output language分开，不用一个含糊选项同时改变两者。第一版一次只采集一场事件，进行中不再提供可暗中创建第二场的Start meeting。

键盘：Enter／Space打开已聚焦入口；Shift+F10或Context Menu键打开菜单；Escape关闭最上层菜单／速览／来源抽屉并恢复触发点焦点，不停止采集。菜单使用平台原生行为或等价方向键导航。

全局快捷键只优先提供Show/hide meeting，默认未分配，允许用户在Settings录入并测试冲突。开始、暂停与结束不默认注册全局键，避免意外采集／停采。快捷键注册失败必须可见，不吞系统按键。无需持续拦截所有键盘输入。

## 6. 视觉语言与材质

浅色为首版基准：纸白内容面、石墨文字、低饱和蓝强调、细分隔。正文建议15px／1.5行高，辅助文字不小于12px，字体优先系统无衬线并配中文回退；当前建议token和对比度校准见[style.md](design/style.md)；[JSON](design/tokens.json)维护当前运行参数。标题不用宣传页式超大字号。

材质仅用于桌面入口、速览、右键菜单与可选轻顶栏。正文／表格／图形底面保持不透明。可采用轻模糊＋接近不透明的底色＋细边界，避免折射、流光、亮边或随鼠标移动的效果。背景颜色不能改变事实状态的辨识。

苹果材质指南用于参考层级、克制和可读性；不是要求实现原生Liquid Glass或更换为SwiftUI。平台原生材质可用且可靠时使用，否则采用同样层级的实色底。模糊、跨窗口透明和真实桌面背景效果必须在目标桌面实测，不把CSS滤镜存在当作等价能力。[S13](sources.md)

响应Reduce transparency、Reduce motion或对应应用内开关；无法读取系统设置时提供明确开关。减少透明度后改用实色底，保留边界；减少动效后无非必要动画。失去窗口焦点或系统降低效果时不影响内容读取。

普通文字对背景对比度目标≥4.5:1，重要图形边界与控件≥3:1。参考图不提供这些保证，需实际验证。材料背景在亮／暗／复杂桌面上都要检查，不能只测白底。

当前已认可图组采用浅色；深色模式仍不是本轮必做范围，不能把其他探索稿当作已确认设计。

## 7. 状态、动效与更新

入口使用[独立图标与状态规范](design/launcher.md)：待命灰点、连接琥珀空心环、采集绿点、暂停琥珀暂停符号、异常红色叹号。会话服务错误覆盖旧采集快照；tooltip、无障碍名称与速览共用状态投影。capturing与Agent processing可同时存在，模型问题另行解释，不用点表示理解质量。

按[Demo实时表达规范](demo-live-visuals.md)，新节点／内容短暂高亮约1.8秒，连线短暂绘制；实际理解／编排期间可显示工作指示和真实模型草稿，空闲时停止运动。减少动效设置关闭动画和过渡。重复状态不重复通知。默认自动跟随；有文字选择时保护对应块，主动查看历史时保留所选版本并提供返回实时入口；旧内容若已失效必须立即标过期，不能等到用户应用布局才提示。

来源缺失、无数据、开始连接、转写有但理解等待、生成失败、试算基线过期、保存失败均有独立文案。不能为填满空白生成假图、假参与者、假百分比。

已保存个人试算仅在其记录的来源、公式或对象／关系依赖发生变化时提示基础条件已变化；无关新发言不触发。历史产物或必要依据缺失时显示“部分原始依据缺失，暂无法完整核对；保留原试算值。”，不冒充已变化或已核对。两种提示均保留原参数／结果，不自动重算。本轮不改变编辑中参数、个人问答或动态组件。

## 8. Agent生成内容如何继承外观

宿主向生成器提供`visualProfileId`、目标尺寸、字体尺度、可用颜色／间距／图形语法和locale。Agent可决定内容结构、图形数量与布局，但不能修改顶栏、采集状态、设置或复制一套新的应用外壳。

SVG中使用token映射的颜色与字号；HTML／chart由隔离宿主注入同一视觉配置。代码净化后仍检查是否绕过字号／对比／边界约束。语义需要多系列颜色时提供有限、可区分的序列色，不强制所有数据同色。

生成器不需要逐次复制磨砂CSS。材质由可信宿主提供；产物以可读内容为主。改变产物语言时允许换行重排，但保持业务对象、来源及试算语义不变。
