# ADR-002：多载体生成式表达与可信宿主

## Status

Proposed｜2026-09-11。Agent生成表达是用户确认要求；具体载体协议和隔离实施为工程建议。

## Context

用户明确要求Agent按会议内容设计文字、关系、图形和交互，工作级、短、清楚。需要不断修订和追溯，而不能每次给固定前端模板填字段或保存不可维护的截图。

## Decision

建议采用ExpressionPlan＋可版本化Artifact。支持结构化文档／表格、图语言、SVG、数据图表和受控HTML。Agent负责语义和组合，宿主负责类型、来源、版本、渲染和业务操作。代码生成与业务状态权限分离。

数字与日期计算使用明确条件的可信工具，展示层只读结果或在已授权试算内预览。生成内容的请求不直接采纳为用户命令；真正修改与确认经可信界面。

## Consequences

正面：允许按内容生成结构；统一来源与更新；载体可逐步实现和替换；特殊图形有自由表达空间。

代价：需实现多适配器、可读性预览与版本绑定；SVG／HTML的校验和隔离不是免费能力；通用元素覆盖不足时要扩展语言。

中性：可先交付部分载体，但必须报告阶段覆盖；不能以静态图通过代替HTML交互或自动表达选择完成。

## Alternatives Considered

- 固定业务组件：实现较少，但不能满足已确认生成自由度。
- 全部手写SVG：表现自由，复杂交互、布局修订和语义维护成本高。
- 全部生成完整HTML应用：自由度大，但会把执行权限、状态与表现混在一起；不作为默认路径。
