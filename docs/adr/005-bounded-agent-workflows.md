# ADR-005：本地持久任务与有界 LangGraph 工作流

状态：2026-09-12本轮工程采用，工作树实现；真实业务语义仍待验收。替代 ADR-004 中共用理解调度、无主动工具分支和预览错误未反馈的实现方式；保留采音、领域服务、SQLite、ModelPort及隔离渲染。

## 背景

用户授权W1–W6完整本地实施，要求自然会议持续理解，同时支持个人推演、来源回查与恢复。仅增加prompt不能让模型真正查询历史，个人等待不能占会议理解锁，框架checkpoint不能替代业务幂等。

## 决定

采用稳定LangGraph JS 1.4.14＋core1.1.48编排两类有界图。SQLite显式持久任务／提案／成功批次承担恢复；不引入MemorySaver或better-sqlite3。业务事务只做本地状态和命令提交，网络／工具／预览在事务外。

实时模型最多2次、个人4次、表达2次；工具、失败与恢复使用同一已用账目。个人请求在发送时冻结基线并独立取消。模型只能提出会议内证据查询、受控计算与表达；不获得外部工具权限。服务分配新ID并核对可信读集／租约fence；表达身份包含scope、branch、purpose及有序对象角色。

## 后果与边界

新增框架依赖与持久任务状态，但领域和存储仍独立可测。聚合快照和任务表重复保存部分信息，现阶段优先正确恢复；长会写入成本未获真实性能证据。检索为本会议词项／版本读取，offset分页不提供跨变化快照隔离；版本和coverage须显式处理。修复只改布局／几何，保守拒绝内容改写。来源字面匹配不等于语义蕴含。
