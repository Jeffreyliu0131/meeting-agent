# ADR-004：连续输入、增量理解与实时工作页

2026-09-11｜本轮采用。测试时为 `5fcd90f` 后的本地工作树，之后纳入 `3f6279a`；实际结果见 [本轮验证](../../tests/results/live-agent-validation.md)。本文替代 ADR-003 中全会议上下文、理解等待预览、手动应用所有更新和音频积压即停止的实现取舍；保留单一可信服务、生成隔离及双平台独立验收。

## 目标

用户明确要求会议持续发生时页面自动演变，并授权实现。默认实时跟随、简短表达、来源可查、个人试算独立。普通阅读不冻结页面；文字选择只保护对应块，历史查看固定版本，个人草稿保持原公式和上下文。

## 执行结构

音频连续进入按通道 FIFO → 带采集时间的来源 → 顺序理解批次 → 先提交语义状态 → 独立表达队列 → 校验与预览 → 局部页面更新。新发言不取消已运行的理解；相关原话修订、语言变化和依赖对象变化阻止过期提交。复杂生成等待时可以继续处理下一批。

`Proposal` 可返回一个完整简单产物、一个 `ArtifactPatch` 或一个 `ExpressionPlan`，三者互斥。复杂内容在理解提交后调用生成器。patch 按块 ID 更新／删除，保留未涉及块；base revision 冲突拒绝。完整历史快照仍保留，便于来源和个人试算追溯。同目的未启动的完整表达计划可合并；patch 不跨版本盲合并。表达队列上限8，超限明确报错并保留重试任务。

个人请求单独形成理解批次，生成的个人对象和产物不会覆盖会议对象。提问可绑定打开时的产物版本；会议继续自动更新，问题依据不静默漂移。Agent 提供的受控操作按钮只产生个人探索请求，不获得采音、文件、网络或会议确认权限。

## 上下文与调用预算

- 保存全部原话与修订；每轮只选未处理来源、近期原话、关键词／中文双字匹配的相关对象、关系与旧证据。相关产物只携带一份，索引与完整历史分开。
- 每轮默认24,000 UTF-8字节的上下文预算，最多24个未处理片段；超预算会缩减可选上下文，不裁掉本批原话。单段本身放不下时明确报错，等待拆分／纠正。已处理来源按 ID＋revision 记录，防止话题排序或纠正导致跳过。
- 当前检索是可解释的词项匹配＋关系邻接，不是向量语义检索；同义改写、远距离隐含指代和检索覆盖仍需要真实模型评估。旧条件没有找回时不允许模型补造。
- 每次请求先持久化调用记录和保守预留，再调用供应商。成功、失败、格式错误和过期响应都保留耗时／用量；供应商未报告用量则明确未知，保守预留不退回。最近一小时明细用于预算，累计总量保留。
- 默认每场会议滚动一小时2,400次供应商调用、4,000,000文本tokens预算；不是跨会议的账户总额度。理解／表达生成单次输出上限2,500 tokens。理解／表达生成的输入文本、指令和schema合计上限60,000字节，作为请求前保守token预留依据。STT记录音频时长，模型未返回token时不将其记成零费用。这些限额是运行参数，不是货币价格承诺。
- `MEETING_MIN_BATCH_MS`默认1,500毫秒，是调度合并参数，不等于端到端延迟。无新内容不启动后台理解。

## 音频连续性与顺序

保留现有约5秒 WAV 切片适配器，本轮不宣称接通 Realtime API。音频使用采集起止时间、通道序号、epoch和段落ID；入库按采集时间排列，输入版本仍按接收提交推进。重叠片段保留各自区间，不能仅凭片段时间判断重叠中的每个词的先后。

每通道包含在途请求最多30秒／2MB音频内存；慢响应排队，溢出丢弃新片段并记录可见缺口，设备继续运行；网络错误记录该片段失败，再处理后续片段。不同通道可并行，同一通道有序。缓冲是有界的，持续过载无法承诺无损。明确停止刷新尾部、释放音轨；已接受音频可继续转写，退出最多收尾2秒，余下记录中断。

## 表达与入口

关系图共享节点、按依赖分层；增量更新保留已有节点位置，内部滚动支持超出可见宽度的结构。环路可展示，但复杂交叉和长标签仍需可读性评审。HTML允许宿主定义的 grid／stack／muted／emphasis／callout 类，仍禁止生成脚本、任意样式和资源访问。

按 [会议入口规范](../meeting-entry-spec.md) 接入：正常音频设置一次保存；可信桌面层处理一键开始与采音；系统语言映射、新会议输出快照、指定设备、自动标题／手工锁定、渐进提问均走显式契约。开发文字／回放入口仅在 `MEETING_DEV_INPUTS=1` 时显示。旧偏好保守保留语言选择；旧标题按用户标题保护。

## 未解决边界

`3f6279a`中的首次完整设置页和采音错误重试缺口，已由后续[前端改造](../sessions/2026-09-11-frontend-refresh.md)接入轻音频设置与采集恢复；真实设备质量仍需独立验收。

没有真实供应商凭证，不能证明语义、命名、转写质量和实际费用。来源存在校验不是事实蕴含校验；模型比较与推演需人工评估。音轨仍是切片，自动说话人分离、逐词时间、流式VAD和真实双端设备路由另测。SQLite仍保存聚合快照，大量历史的写放大／分页尚未优化。Windows真机、安装器和签名不由macOS程序测试证明。
